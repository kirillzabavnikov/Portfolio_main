# Результаты проверки

25 октября 2026. Проверена production-сборка Next.js со статическим экспортом.

## Технические проверки

- `node scripts/validate-content.mjs`: 5 опубликованных проектов, уникальные slug, все обложки и иллюстрации существуют, заданы размеры, полные оригиналы сохранены.
- `npm run build`: успешно; главная, 5 кейсов, favicon и 404 экспортированы в `out/`.
- `npm run typecheck`: успешно.
- `npm run lint`: успешно, без предупреждений.

## Браузер и визуальный аудит

Chromium, viewport 1440×1000, 768×1024 и 390×844. Главная и все пять кейсов — 18 сочетаний маршрута и размера экрана. Проверялась production-версия, обслуживаемая локальным статическим сервером.

Первая итерация выявила запрос отсутствующего favicon и проблему перевода фокуса при открытии мобильного меню. Добавлен favicon, фокус назначается после обновления отображения; обработчик Tab удерживает его внутри меню. Также сокращено вступление для мобильной версии. Во второй итерации проверены обновлённые страницы целиком; диагональный знак внешней ссылки убран из текста из-за отсутствующего глифа в среде. Финальные скриншоты сохранены в `qa-second/`, машиночитаемый отчёт — `qa-second/report.json`.

Проверено:

- HTTP 200 для главной и всех кейсов.
- Все изображения загружаются, имеют alt и размеры.
- Нет горизонтального переполнения на трёх проверенных размерах.
- На каждой странице ровно один h1, заданы title, description и Open Graph.
- В консоли нет ошибок JavaScript и загрузки ресурсов.
- Открытие/закрытие мобильного меню, блокировка прокрутки фона, Shift+Tab/Tab, Escape и возврат фокуса.
- Hover обложки scale(1.02), отключение переходов при prefers-reduced-motion.
- Переход по карточке и переход к следующему кейсу.
- Сгенерированная страница 404 содержит возврат к проектам.

Внешние ссылки на Telegram, email и Notion сверены с исходным портфолио. Их доступность из всех внешних сетей не проверялась. Автоматический поиск маршрутов проверяет шесть реальных страниц; неизвестные адреса обрабатываются 404 на уровне хостинга.

## Реальные материалы и ограничения

Получены и импортированы все **26 файлов из пяти RAR-архивов**. Исходные PNG сохранены в `content/original/images/`, для сайта подготовлены WebP. Сжатые изображения занимают около 4.1 МБ против примерно 27 МБ оригиналов. Тексты Notion сохранены полностью в JSON и Markdown; ссылки доступных изображений в читаемых оригиналах переведены на локальные файлы.

В исходном Notion дополнительно перечислены 5 готовых горизонтальных обложек, 1 экран редактора и портрет автора. Эти 7 файлов не были в архивах и не загрузились из-за сетевой блокировки file.notion.so. Полный перечень — `content/original/import-status.json`. На опубликованных страницах отсутствующие файлы не запрашиваются. Обложки собраны CSS-раскладкой из предоставленных экранов без кадрирования и дорисовки. Портрет не используется.

Основные отличия от референса: Inter с кириллицей вместо Whyte; русские тексты и другие переносы; реальные проекты и контакты Кирилла; обложки из предоставленных экранов; нет чужого личного логотипа и инфраструктуры блога. Сетка, цвета, типографический масштаб, интервалы, мобильное перестроение и основные взаимодействия повторяют исследованный референс.

## Подготовка публикации

Site зарегистрирован ранее; повторное создание не выполнялось. Идентификатор сохранён в `.openai/hosting.json`. Публикация использует статическую папку `out/`. Пользовательские оригиналы и исследовательские материалы остаются в исходниках и не включаются в опубликованные веб-ресурсы. Аудитория сохраняется приватной, доступной владельцу.

В окружении отсутствует поставляемый Sites `site-workflow.mjs`. Для отправки исходников используется обычный Git с краткосрочным credential в памяти и скрытым stdin (`scripts/site-source.py`); credential не записывается в файлы. Архив публикации содержит только `.openai/hosting.json` и `out/`.
